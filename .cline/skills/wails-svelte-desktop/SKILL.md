# Wails v2 + Svelte Desktop Expert

Специализируется на архитектуре, стилизации и UX десктопного интерфейса Wails v2 + Svelte (TypeScript).

## Зоны ответственности:
1. Компоновка и рабочие режимы:
   - Трехзональный интерфейс: Меню и режимы -> Панель вкладок + Форма метаданных + Текстовый редактор спецификаций -> Панель предпросмотра листа А4.
   - Переключение рабочих экранов: [⚖ Сплит] (50/50), [📝 Только ввод] (100% ширина редактора), [🔍 Только превью] (100% ширина предпросмотра).
2. Боковая панель вкладок (Arc / Chrome style):
   - Расположена слева, плавно сворачивается по кнопке в шапке (`◀ Вкладки` / `▶ Вкладки`).
   - Имя вкладки содержит только номер заявки (до 5 символов, обрезка с многоточием: `52`, `12345...`).
   - Индикатор несохраненных данных: белый кружок `○`, который гаснет сразу после успешного сохранения на диск.
   - Закрытие вкладки (`×`) с модальным диалогом подтверждения при наличии несохраненных изменений.
3. Форма метаданных:
   - Адаптивная flex/grid-верстка с минимальной высотой по вертикали.
   - Поля «Должность» и «ФИО» (инициатор и куратор) делят строку строго поровну ($50\% / 50\%$).
   - Поле «Требования» располагается отдельной нижней строкой на $100\%$ ширины.
   - Календарь для дат (ДД.ММ.ГГГГ) с кнопками «Сегодня» и «Очистить».
4. Редактор инструмента:
   - Вертикальный столбец нумерации строк (gutter), отделенный от текстового поля (номера строк не выделяются и не попадают в буфер обмена).
   - Мягкая фоновая подсветка текущей активной строки курсора.
   - Перенос строк (`word-wrap`) без появления горизонтального скроллбара.
   - Тонкие стилизованные скроллбары в стиле VS Code.
   - Шрифт по умолчанию: `Cascadia Code` (фолбек `Consolas`), 12pt.
5. Интерактивное печатное превью:
   - Горизонтальное центрирование макета А4 при любой ширине панели.
   - Масштабирование (Zoom -, 100%, +, 1:1, Ctrl + колесо мыши) и пагинация (◀ Стр. X из Y ▶).
6. Drag-and-Drop:
   - Прием перетаскиваемых файлов `.md` и `.txt` из Проводника Windows (через Wails `runtime.OnFileDrop` или HTML5 drop-события) с автоматическим парсингом в новую вкладку.
7. Темы Catppuccin и Хоткеи:
   - Поддержка Mocha (#1e1e2e), Macchiato, Frappé, Latte. Исключение нестилизованных белых областей.
   - Хоткеи по `KeyboardEvent.code`: `Ctrl+S`, `F5`, `Ctrl+Z`, `Ctrl+Y` работают одинаково стабильно в RU и EN раскладках.
