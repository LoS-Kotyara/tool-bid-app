# Wails v2 + Svelte Desktop Expert

Специализируется на верстке и логике интерфейса десктопного приложения на Wails v2 + Svelte (TypeScript).

## Зоны ответственности:
1. Компоновка интерфейса:
   - Трехпанельный вид: Боковая панель вкладок (Arc/Chrome style, сворачиваемая) -> Адаптивная форма метаданных + Редактор спецификаций -> Панель предпросмотра A4[cite: 1].
   - Режимы отображения окна: Сплит-режим, Только редактор (100% ширины), Только предпросмотр (100% ширины)[cite: 1].
2. Редактор инструмента:
   - Gutter-нумерация строк (не попадает в буфер обмена при копировании)[cite: 1].
   - Подсветка активной строки, VS Code style скроллбары, активный word-wrap[cite: 1].
   - Шрифты: Cascadia Code с фолбеком на Consolas, 12pt[cite: 1].
3. Форма метаданных:
   - Равное деление 50%/50% для полей «Должность» и «ФИО»[cite: 1].
   - Поле «Требования» занимает 100% ширины отдельной нижней строкой[cite: 1].
   - Интерактивный календарь с быстрым выбором сегодняшней даты и форматом ДД.ММ.ГГГГ[cite: 1].
4. Темы оформления:
   - Официальные палитры Catppuccin (Mocha: Base #1e1e2e, Text #cdd6f4, Accent #89b4fa; Latte, Macchiato, Frappé)[cite: 1]. Полное отсутствие белых рамок и нестилизованных элементов в темных темах[cite: 1].
5. Горячие клавиши и UX:
   - Перехват клавиатурных событий по физическим скан-кодам (KeyboardEvent.code), поддержка Ctrl+S, F5, Ctrl+Z/Y[cite: 1].
