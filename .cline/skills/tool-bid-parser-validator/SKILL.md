# Tool Bid Parser & Validator

Специализируется на сериализации, парсинге, валидации канонического Markdown (.md) и Python-конвертере входящих заявок.

## Зоны ответственности:
1. Двусторонний Markdown-парсер (Go):
   - Заголовок: разбор номера и даты по регулярному выражению `^#(?P<num>\S+)\s+от\s+(?P<date>\d{2}\.\d{2}\.\d{4})`.
   - Валидация строгого календарного формата `ДД.ММ.ГГГГ` (с 4-значным годом).
   - Построчный разбор метаданных с префиксами: `Подразделение:`, `Пункт:`, `Инициатор:`, `Куратор:`, `Дата поставки:`, `Требования:`, `Цель:`.
   - Разбор подписантов: разделение должности и ФИО через `;` с обязательной очисткой от концевых точек с запятой и лишних пробелов.
   - Контроль обязательной пустой строки-разделителя перед спецификацией.
   - Парсинг позиций инструмента с конца строки:
     * `parts[0]` — наименование
     * `parts[-1]` — количество
     * `parts[-2]` — единица измерения
     * Внутренние характеристики склеиваются обратно: `"; ".join(parts[1:-2])`
     * Сохранение оригинальных точек с запятой внутри характеристик (например, грануляция алмазной пасты `20/14; 16/12`).
   - Контроль отсутствия маркеров списка (`-`, `*`, `+`).
2. Сериализатор в Markdown:
   - Формирование каноничного `.md` документа с гарантированной пустой строкой и правильным форматированием строк спецификации.
3. Скрипт импорта заявок (scripts/excel_to_md.py и scripts/run_converter.bat):
   - Drag-and-Drop обработка файлов Excel через `.bat` (без конфликтов со спецсимволами и скобками в пути).
   - Чтение объединенных ячеек (`merged_cells`).
   - Универсальное извлечение подписантов из столбцов C–F независимо от конкретного смещения.
   - Нормализация дат любых типов (`datetime`, `date`, `DD.MM.YY`, `MM/DD/YYYY`) в строгий вид `ДД.ММ.ГГГГ`.
   - Сохранение внутренних `;` в названиях позиций без автозамены на запятые.
