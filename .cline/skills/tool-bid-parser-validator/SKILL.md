# Tool Bid Parser & Validator

Специализируется на сериализации, десериализации и валидации формата заявки Markdown (.md) и Python-конвертере.

## Зоны ответственности:
1. Markdown канонический парсер (Go):
   - Парсинг заголовка: регулярное выражение `^#(?P<num>\S+)\s+от\s+(?P<date>\d{2}\.\d{2}\.\d{4})`[cite: 1].
   - Парсинг метаинформации: построчное чтение префиксов (`Подразделение:`, `Пункт:`, `Инициатор:`, `Куратор:`, `Дата поставки:`, `Требования:`, `Цель:`)[cite: 1].
   - Разбор подписантов: разделение роли и ФИО через знак `;` без концевых знаков препинания[cite: 1].
   - Парсинг спецификации: разделение строк инструмента по `;` (`Наименование; Характеристики; Ед. изм.; Количество`)[cite: 1].
2. Валидация:
   - Контроль даты в строгом формате ДД.ММ.ГГГГ[cite: 1].
   - Обязательное наличие пустой строки перед спецификацией[cite: 1].
   - Проверка количества и единиц измерения[cite: 1].
3. Консольный конвертер excel_to_md.py:
   - Автономный Python-скрипт с поддержкой drag-and-drop через .bat[cite: 1].
   - Чтение объединенных ячеек OpenPyXL, нормализация дат в ДД.ММ.ГГГГ, очистка лишних точек с запятой[cite: 1].
