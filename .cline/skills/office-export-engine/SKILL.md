# Office Export Engine (Go XLSX, ODS & PDF)

Специализируется на генерации электронных таблиц и печатных документов строго по заводскому шаблону.

## Зоны ответственности:
1. Модуль XLSX (github.com/xuri/excelize/v2):
   - Геометрия столбцов: A: 4.14, B: 29.57, C: 20.85, D: 21.57, E: 8.43, F: 9.29.
   - Геометрия строк (pt):
     * R1: 15.0, R2: 5.25, R3: 15.0, R4: 4.5, R5: 27.0, R6: 35.45, R7: 33.6, R8: 4.5.
     * R9: 16.5, R10: 4.5, R11: 32.25, R12: 54.75, R13: 15.0, R14: 33.0, R15: 54.0, R16: 3.0, R17: 16.5, R18: 4.5.
     * R19 (шапка спецификации инструмента): 36.0.
     * R20+ (строки инструментов): 30.0.
   - Объединения:
     * C1:F1 (подчеркивание номера заявки, border bottom thin).
     * D3:F3 (блок подразделения, контурная рамка medium).
     * A6:B6, A7:B7 («ИНИЦИАТОР ЗАКУПКИ», «КУРАТОР ЗАКУПКИ»).
     * A9:F9 («I. Общие сведения»).
     * B11:C11, D11:F11; B12:C12..B15:C15; D12:F12..D15:F15.
     * A17:F17 («II. Техническая часть документации»).
     * C19:D19 (шапка «Характеристики товара») и объединение C:D на каждой строке позиций (R20+).
   - Настройки печати: Portrait, `FitToWidth = 1`, сквозной заголовок строк (`_xlnm.Print_Titles` = `'Заявка'!$19:$19`).
2. Автономный генератор ODS (OpenDocument Spreadsheet):
   - Использование исключительно стандартных библиотек Go `archive/zip` и `encoding/xml` (без CGo и внешних утилит).
   - `mimetype` записывается первым файлом без компрессии (`zip.Store`), значение: `application/vnd.oasis.opendocument.spreadsheet`.
   - Полная структура манифеста (`META-INF/manifest.xml`), стилей (`styles.xml`) и контента (`content.xml`).
   - Фиксированные ширины колонок в сантиметрах: A: 1.0cm, B: 6.0cm, C: 4.3cm, D: 4.3cm, E: 1.7cm, F: 1.9cm.
   - Гарантированная валидность и совместимость для открытия в Apache OpenOffice Calc и LibreOffice Calc.
3. Генератор печатного HTML/PDF:
   - Чистый HTML/CSS макет страницы A4 с полями 10 мм.
   - `thead { display: table-header-group; }` для авто-переноса шапки спецификации на последующие листы.
   - `tr { page-break-inside: avoid; }` для предотвращения разрыва строк инструмента.
